# デザイン刷新ブリーフ(v2)

運営者の評価：「文字が多すぎる」「カードのデザインが微妙」「出典の注釈や確定マークが多くて見づらい」。
目標：VALORANT風で統一感があり、**余白が多く、ひと目でわかる、オシャレな**サイト。読ませるより「見せる」。

## 原則
1. **1画面1メッセージ**。各セクションは「大きな見出し＋1〜2行のリード＋ビジュアル(カード/図)」まで。詳しい文章は「MORE +」で開く(`<details>`、アニメーション付き)か、下層ページへ
2. **ページを分ける**。長いページは作らない。目安：1ページ3〜5セクション
3. **注記を減らす**。
   - 「確定」マークは表示しない(確定が標準)。報道ベース・未確定のときだけ、小さな点＋「報道」「未定」を控えめに付ける(1行に最大1つ)
   - 出典はページ本文から外し、ページ最下部の折りたたみ「出典・確認状況」にまとめる
   - 画像クレジットも同様に最下部の折りたたみへ
4. **カードは少なく、大きく、間隔を広く**。gap 24〜32px(スマホ16〜20px)。カード内の要素は3つまで(見出し・1行・リンク)。罫線を重ねない
5. **ロゴ・写真の枠を空けておく**(運営者が後で入れる)
   - サイトロゴ：ヘッダー左に `.slot-logo`(今は文字ロゴ「VCT FAN」、画像が入れば差し替え)
   - チームロゴ：`assets/img/teams/<slug>/logo.png` があれば表示、なければチーム略称の文字を入れた空枠
   - 選手写真：縦長(3:4)の枠。写真がなければシルエット風の空枠＋選手名
   - チーム写真：横長(16:9)の枠
   - JSONの `images.logo` / `images.hero` / `players[].photo` を使う。枠のサイズは写真が入っても崩れないよう固定比率

## 見た目(VALORANT風)
- 配色：ネイビー #0F1923(背景)、#1F2731(面)、レッド #FF4655(アクセント)、クリーム #ECE8E1(文字・明るい面)、グレー #8B978F(補助文字)。シアン #45D4E0 はごく一部の差し色だけ
- 明るいクリーム地のセクションを時々挟み、暗い面と交互にしてリズムを出す
- 形：右下や左上を斜めに切った角(clip-path)、細い1pxの線、角の小さな四角マーカー、大きな背景数字
- 文字：英字見出しは Anton または Bebas Neue(大文字・字間広め)、和文は Noto Sans JP(見出し700、本文400)。本文16px、行間1.8、1行は最大36字程度
- ボタン：VALORANT風の枠線ボタン(ホバーで赤が左から満ちる)

## メニュー
- 全幅でハンバーガー(右上)。開くと全画面オーバーレイ(ネイビー、項目がずれて順に表示)
- グループ：
  - HOME
  - 大会システム：概要 / 1年の流れ / 大会の種類 / ルールと支援金 / 用語集・FAQ
  - チーム：Pacific パートナー / 日本チーム
  - 日本：日本予選 / VCJの歴史
  - ニュース
- ヘッダーは小さく(高さ64px)、スクロールで背景が付く。PC幅では「大会」「チーム」「日本」「ニュース」の4つだけヘッダーにも並べてよい

## アニメーション
- 読み込み時：見出しが下からスッと出る、カードが順番にフェードイン(stagger)
- スクロール：要素がビューに入るとフェード＋少し上へ(IntersectionObserver)
- ホバー：カードが少し浮く＋赤いラインが伸びる、写真がわずかにズーム
- 数字のカウントアップ(支援金など)、タイムラインの線が伸びる
- メニュー開閉、MORE の開閉もアニメーション
- `prefers-reduced-motion` では全部止める。JSなしでも内容は全部見える

## ページ構成(案)
```
index.html                 HOME：ヒーロー、3つの入口(大会/チーム/日本)、最新ニュース3件、東京Cup 2
format/index.html          大会システム概要：2027の変化3点、流れの簡易図、下層への入口
format/season.html         1年の流れ：タイムライン(3サイクル)、日程は MORE で
format/events.html         大会の種類：5種類のカード、詳細は MORE
format/rules.html          オープン形式・パートナーのルール・支援金(棒グラフ)・2026との違い
format/glossary.html       用語集・FAQ(アコーディオン)
teams/index.html           チーム入口：Pacific / 日本 の2つ
teams/pacific.html         Pacific 8チームのロゴ枠グリッド
teams/japan.html           日本チームのグリッド(ロスター状況で絞り込み)
teams/<slug>.html          チーム詳細：ヒーロー(ロゴ枠＋チーム写真枠)、タブ(概要/選手/実績/ニュース)
japan/index.html           日本予選：Kickoffまでの道(図)、日程、招待チーム
japan/history.html         VCJの歴史(年ごとのカード、横スクロール or タイムライン)
news/index.html            ニュース一覧(大きめのカード、カテゴリ絞り込み)
news/<id>.html             ニュース詳細
```
- 旧URL(format.html, japan.html, news.html)は、新ページへ案内する短いページ(meta refresh)を残す
- データ(data/*.json)の形は変えない。表示側(scripts/build.mjs とテンプレート)を作り直す

## チーム詳細の文字量
- 最初に見えるのは：チーム名、地域・拠点、ひと言(初心者向け)、選手5人の写真枠
- 歩み・プレースタイル・見どころ・実績は、それぞれ2行まで見せて MORE で全文
- 「確認できなかった点」は最下部の折りたたみへ

## 品質チェック
- 375px と 1280px でスクリーンショットを撮って見る。横スクロールなし、壊れた画像なし、リンク切れなし
- 1画面に表示される文字の量が以前の半分以下になっているか、見て確かめる
